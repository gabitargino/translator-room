translator-room · 同传房间

Para usar o microfone, o celular precisa confiar no certificado deste notebook. Faça isto uma vez em cada celular.
手机需要先安装并信任本电脑的证书（每部手机只需一次）。

1. Baixar o certificado · 下载证书

Android (Chrome)

  1. Toque no botão acima e baixe translator-room-ca.crt.
  2. Configurações → Segurança → Mais configurações de segurança → Criptografia e credenciais → Instalar um certificado → Certificado de CA.
  3. Confirme (“Instalar mesmo assim”) e escolha o arquivo baixado.
设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书 → 选择下载的文件。

iPhone (Safari)

  1. Abra esta página no Safari e toque no botão acima → Permitir.
  2. Ajustes → Perfil Transferido → Instalar.
  3. Ajustes → Geral → Sobre → Ajustes de Confiança de Certificados → ative a confiança total no certificado “Caddy Local Authority”.
设置 → 已下载描述文件 → 安装；然后 通用 → 关于本机 → 证书信任设置 → 开启完全信任。 2. Abrir a sala · 打开房间

Se o navegador ainda avisar que a conexão não é segura, o certificado não foi instalado ou não recebeu confiança total. O certificado só vale para este notebook.
